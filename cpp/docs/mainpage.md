# graph-matching: C++ implementation

Parallel maximal matching of weighted graphs with one-way and N-way
handshaking. This is the C++ implementation's API reference. The source is on
[GitHub](https://github.com/galudino/graph-matching), and the
[C implementation](../c/) has its own reference.

The C++ implementation is in progress. Its components so far:

| Component | Headers | Contents |
|-----------|---------|----------|
| graph     | edge.hpp, graph.hpp | Edges and sorting them, and graphs stored as adjacency arrays, read from Matrix Market files |
